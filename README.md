# AV At-Scale Deployment Readiness Checklist (v1.0)
Mobility COE AV-Scale Readiness Checklist

An interactive version of the checklist from the Mobility Center of Excellence
(Center of Excellence on New Mobility and Automated Vehicles).

**Open the checklist:** https://ccorreaj.github.io/mcoe-av-readiness-checklist/

**Download the report and Excel workbook:** [TBD]

## About
The checklist helps state and local agencies assess their readiness for at-scale
AV deployment across seven domains. It is a planning and self-assessment tool,
not a set of strict requirements, a compliance audit, or a pass-fail score.

## Using the page
- Rate each item's maturity from 1 to 3, and adjust its priority if needed.
- Add evidence, status notes, and dates.
- Follow dependency links between related items.
- Review results on the Summary tab.

## Your data
This page has no accounts or database. Your entries stay in your browser on your
device, and clearing browser data removes them. Use **Save progress file** to keep
a copy or share it with colleagues, and **Export table (CSV)** to get the full table.
